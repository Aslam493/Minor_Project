MOTIVATION AND PROBLEM

CAN trusts every frame, and Linux can lie about it

CAN connects a vehicle’s brakes, engine and steering, but nothing checks who sent a frame. Can we trust the frame, the decision made on it, and the record kept later?

Spoofed ID

Any node can send any ID

Tampered data

Payload changed on the way

Replayed frame

An old valid frame sent again

Silence

Frames or checks quietly stopped

Goal: detect all four from OP-TEE Secure World, a part of the processor kept apart from Linux, so the verdict stays trustworthy even if Linux is compromised.

Secure CAN Monitor · Raspberry Pi 3 · OP-TEE

Four ways a CAN stream can be attacked. A checker running in Linux cannot be trusted if Linux itself is compromised: it could hide any of these. So the goal is to judge frames from Secure World, a place Linux cannot change.
