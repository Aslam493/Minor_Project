Secure CAN Monitor · Raspberry Pi 3 · OP-TEE

Two terminals. Terminal 1 is the sender Pi, which plays the ECU and the attacker. Terminal 2 is the receiver, showing what Secure World decides. First the receiver proves it is running: Linux sees 3 cores, OP-TEE 4.10 answers, and the monitor status shows Mode P. Then six steps: healthy traffic, silence, a tampered tag, a replay, a counter jump, and finally stopping Linux’s forwarder. Each time Secure World records the right verdict. The full commands are in the live demo guide.
