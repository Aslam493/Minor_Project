Secure CAN Monitor · Raspberry Pi 3 · OP-TEE

By September the foundation was in place. The Raspberry Pi boot chain was extended with TF-A and OP-TEE. The key change is in BL31, the secure monitor at EL3: when Linux brings up CPU1, the request is intercepted and the core is sent into Secure World, where it runs the monitor loop forever. Linux keeps CPU0, 2 and 3. This was proven on hardware and is still how the final system works.
