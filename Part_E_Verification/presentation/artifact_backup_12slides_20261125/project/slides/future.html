Future work in order of importance. First, a forward-secure audit log following Schneier and Kelsey, so that even a compromised Linux cannot alter past evidence: this answers the third trust question. Second, an EL2 stage-2 memory guard, as in MyTEE, to make up for the missing TZASC. Third, larger batches for more throughput, since the CPU is mostly idle. Fourth, proper key provisioning and a separate flood alarm, which completes the rate-and-flood promise.
