Secure CAN Monitor · Raspberry Pi 3 · OP-TEE

The second half of the September work: a CAN frame travelled from the MCP2518FD chip on SPI0, through the GPIO25 interrupt routed as a secure FIQ, to core 1, which copied it into a secure buffer and checked it. ID, replay and timestamp checks were proven on real frames. HMAC was blocked because Secure World was unexpectedly slow. Three of seven milestones were proven. After midterm we changed how frames reach Secure World, because on the Pi 3 the SPI controller cannot be locked to Secure World; the next slides show the final design.
