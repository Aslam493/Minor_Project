Each frame is checked in the cheapest order: the CAN ID first, before any crypto (6.7 microseconds), then the 32-byte HMAC tag made with the shared key, compared in constant time, then the counter, which must be exactly one more than the last accepted one (54.6 microseconds per valid frame). Secure World also runs its own clock. Each line is one attack sent on the real bus, stopping at the wall that catches it: wrong ID at the ID check, changed data at the HMAC, old, repeated, conflicting or skipped frames at the counter, and silence, a killed forwarder or late answers at the clock. Timing values, measured: a 5-minute heartbeat test, 321 answers on time and 0 late over 320 seconds (forwarder counters); 6,361 frame requests, all on time; with the forwarder frozen, 8 answers were late and both the forwarder and the Secure World counted 8 (the Secure World count may include one heartbeat). Each attack moved only its own counter, by exactly one.
