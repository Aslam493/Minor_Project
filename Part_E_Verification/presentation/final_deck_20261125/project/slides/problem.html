Secure CAN Monitor · Raspberry Pi 3 · OP-TEE

Three trust questions, from the midterm: the message, the decision, and the record. This work answers the first two. The third, a log Linux cannot rewrite, is designed but not built, and is the first item of future work. Four ways a CAN stream can be attacked. A checker running in Linux cannot be trusted if Linux itself is compromised: it could hide any of these. So the goal is to judge frames from Secure World, a place Linux cannot change.
