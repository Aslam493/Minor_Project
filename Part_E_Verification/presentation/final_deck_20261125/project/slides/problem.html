Secure CAN Monitor · Raspberry Pi 3 · OP-TEE

Motivation. Picture a car: the brakes, the engine and the steering are separate small computers, called ECUs, and they talk over one shared wire, the CAN bus. Every node on the bus trusts every frame it sees, because a CAN frame carries no proof of who sent it. So anyone who gets onto the bus, the attacker in red, can send a forged frame. Four attacks follow: a spoofed ID, tampered data, a replayed old frame, and silence, where frames or checks quietly stop. Problem one: any node can send any frame. Problem two: the check on those frames runs in Linux, and Linux can be compromised; a compromised Linux can accept forged frames or hide the evidence, so the verdict itself cannot be trusted. Problem three: the record of what happened can be rewritten afterwards; this third problem is future work, a log Linux cannot rewrite. These are the three trust questions from the midterm: can we trust the frame, the decision made on it, and the record. The goal of this project is to detect these attacks from the Secure World of the processor, where Linux cannot hide them.
