## Rules that apply to every component

- Backup image + sha256 before any change. Spare SD card only (two-card protocol); original card untouched.
- No `git stash`. Save `git diff` + untracked files instead (audit O-02).
- `PLATFORM=rpi3` on every optee_os build. Full pipeline: optee-os, tf-a, host apps, buildroot, update_bootfs, sdcard-image.
- Prove new code runs with a new-PTA-command probe.
- Step 2 regression on both profiles (Step 2 profile and Monitor profile).
- Rollback = copy the backup to `out/rpi3-sdcard.img` and flash immediately; no `make` in between.
- `rpi3_can_fiq.c` is not edited. No TF-A source change.
- Detection only; no prevention claims. Pi 3 has no TZASC.
